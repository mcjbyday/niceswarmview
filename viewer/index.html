How to review a wave here

  1. Pick the rig, then Wave and the delta (a bead id or a named wave).
  2. Read the shift notes in the left pane beside the counts: what the worker says moved.
  3. Open anything flagged (red outline) or changed (amber): the right pane lists what shifted, the beads that touched it, and the unified diff of its file.
  4. Mark each module reviewed (checkbox in the right pane, or v); green outline on the node, count in the summary. n jumps to the next unreviewed changed module.
  5. Double-click a node, or click a member, to land in the file in VS Code. r or the reset button brings you back to the whole picture.

Seeing the code change

  • In this page: the right pane shows the unified diff for the selected module's file; the left pane lists every changed file in the wave with its diff.
  • On GitHub: the wave panel links to compare base...head (the Files changed view, with its own "Viewed" checkboxes) and to any pull request that contains the head commit.
  • In VS Code, after landing in the file: Ctrl/Cmd+Shift+G opens Source Control; the Timeline view at the bottom of the Explorer lists the file's commits, click one to open its diff; or F1 then Git: Open Changes for the working tree diff. The wave panel's "copy diff command" button puts git diff base head -- file on the clipboard for a terminal.

Keys

  • h this help · r reset · v toggle reviewed · n next unreviewed · [ ] collapse panes · Esc close or deselect · wheel zooms, drag pans

Colors

  • Wave: green added, amber changed, red dashed removed, gray unchanged, red outline threshold flag. Metrics: red to green grade 1 to 10, gray no data. Rows: importers above, leaves below.
